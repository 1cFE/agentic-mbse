# Project management

**Last Updated**: 2026-10-04

This directory tracks development of agentic-mbse. Installed modeling projects use their own `knowledge/`, `modeling_project/`, and `work/` records; see the repository's `CLAUDE.md` for the two contexts.

| Record | Purpose |
|--------|---------|
| [CURRENT_WORK.md](CURRENT_WORK.md) | Current state, actual remaining work, and next actions |
| [backlog/BACKLOG.md](backlog/BACKLOG.md) | Recorded priorities, remaining capabilities, and dispositions |
| [backlog/epic_*.md](backlog/) | Epic scope and item progress |
| [active/README.md](active/README.md) | Inventory separating open work from retained completed evidence |
| [completed/CHANGELOG.md](completed/CHANGELOG.md) | Completed work and integration history |
| [research/](research/) | Prior investigations; consult before repeating research |
| [reports/](reports/) | Point-in-time status and reconciliation evidence |

The personal `$my-pipeline` skill is the canonical developer workflow map. Use the smallest applicable stages for the work. Keep durable implementation progress with the work item, preserve historical reviews as scoped evidence, and update current tracking when later work supersedes old blockers.

The October 4 refresh keeps completed artifacts at existing paths to preserve references. A folder in `active/` does not by itself establish unfinished implementation; use the reconciled inventory.
