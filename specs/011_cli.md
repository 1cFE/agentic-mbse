
## Purpose
Provide command-line interface for document extraction, batch processing, triage report generation, cache management, and retry operations.

## Requirements
- `extract` command: single document extraction with format override
- `extract-batch` command: batch extraction from JSONL file
- `triage-report` command: generate triage report from existing provenance
- `clear-cache` command: invalidate discovery cache entries
- `retry-failed` command: retry failed/partial documents in output directory
- Typed exit codes: 0 (success), 1 (partial success), 2 (fatal error)
- Structured error messages for invalid input
- Automatically create output directories if missing

## Acceptance Criteria
- **Given** valid DOI, **when** `agentic-mbse extract 10.1234/foo` is run, **then** exit 0 and write output.md + provenance.json
- **Given** invalid identifier format, **when** `agentic-mbse extract bad_input` is run, **then** exit 2 with message "Invalid identifier format: bad_input. Expected DOI (10.xxxx/...) or arXiv ID (YYMM.NNNNN)"
- **Given** batch JSONL with malformed line, **when** `extract-batch` is run, **then** exit 2 with message "Invalid JSON on line {N}: {error}"
- **Given** batch where 3/10 documents fail, **when** `extract-batch` completes, **then** exit 1 and write triage report
- **Given** output directory missing, **when** any command is run, **then** create directory (mkdir -p behavior)
- **Given** `--format=pdf` override, **when** extract is run, **then** skip discovery and only attempt PDF
- **Given** `clear-cache --identifier=doi:10.1234/foo`, **when** run, **then** remove cache entry and exit 0
- **Given** `retry-failed` on directory with successes, **when** run, **then** skip successes and only retry failures

## Interfaces
**Commands:**
```bash
agentic-mbse extract <doi|arxiv_id|file_path> [--format=auto|pdf|jats|arxiv_html] [--output-dir=OUTPUT_DIR] [--format-hint=jats_xml|...]
agentic-mbse extract-batch <input.jsonl> --output-dir OUTPUT_DIR
agentic-mbse triage-report OUTPUT_DIR [--output=TRIAGE_REPORT.md]
agentic-mbse clear-cache [--max-age-days=30] [--identifier=IDENTIFIER]
agentic-mbse retry-failed OUTPUT_DIR
