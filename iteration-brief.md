# Iteration 1 Brief

This iteration addresses the two highest-impact extraction quality gaps found across the 7-paper corpus: **false-positive table detection** and **false-positive heading detection** — both caused by using extraction tool parameters suboptimally, not by missing postprocessing logic. The table fix is a single parameter change (`table_strategy="lines"` → `"lines_strict"`) that eliminates 252 `<br>` HTML tags and 45 `ColN` placeholder columns from aries_cost_account while having zero impact on papers with real ruled tables (hsu_2020, helios_design). The heading fix extends the `AcademicHeaderDetector`'s Guard 2 to require font differentiation for ALL depth-1 section numbers without a trailing period, not just numbers 1–9, which eliminates 2 confirmed false positives in hawker_2020 (a figure caption fragment and a bibliography entry). Both fixes are upstream, tool-level improvements that generalize by design — they use the extraction library's own detection logic correctly rather than patching its output with downstream regex. A new PDF (woodruff_2026, 25 pages, deeply nested heading structure) is added to the corpus per the progressive challenge rule. Success is measured by: all corpus tests passing, zero `<br>`/`ColN` artifacts in aries_cost_account, zero false-positive headings in hawker_2020, and the new paper extracting within bounds.
