# Iteration 2 Brief

This iteration eliminates phantom headings — the dominant structural quality problem remaining after iteration 1 successfully fixed heading detection. Investigation reveals that 60-80% of detected headings in several papers are false positives: reference entries, footnotes, table column headers, figure labels, and address fragments incorrectly promoted to `##` headings. The problem originates from two independent code paths — the `AcademicHeaderDetector` (Pattern 1 treats footnote numbers and years as section numbers; Pattern 2's `isupper()` check is fooled by sparse-letter fragments) and `promote_plain_headers` in postprocessing (no upper bound on section numbers, no rejection of addresses/figure-refs). Both fixes are highly generalizable because they tighten existing logic rather than adding format-specific patterns. Success is measured by reducing phantom heading counts while preserving legitimate section headings across all 7 corpus papers.
