# MultiplicityRange <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#multiplicityrange-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">MultiplicityRange</span></span><a href="#syside.MultiplicityRange" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`MultiplicityRange`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> A <span class="pre">`MultiplicityRange`</span> is a <span class="pre">`Multiplicity`</span> whose value is defined to be the (inclusive) range of natural numbers given by the result of a <span class="pre">`lower_bound`</span> <span class="pre">`Expression`</span> and the result of an <span class="pre">`upper_bound`</span> <span class="pre">`Expression`</span>. The result of these <span class="pre">`Expressions`</span> shall be of type <span class="pre">`Natural`</span>. If the result of the <span class="pre">`upper_bound`</span> <span class="pre">`Expression`</span> is the unbounded value <span class="pre">`*`</span>, then the specified range includes all natural numbers greater than or equal to the <span class="pre">`lower_bound`</span> value. If no <span class="pre">`lower_bound`</span> <span class="pre">`Expression`</span>, then the default is that the lower bound has the same value as the upper bound, except if the <span class="pre">`upper_bound`</span> evaluates to <span class="pre">`*`</span>, in which case the default for the lower bound is 0.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=94" class="reference external" target="_blank">7.4.12</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=256" class="reference external" target="_blank">8.3.4.11.2</a> of the KerML specification.
