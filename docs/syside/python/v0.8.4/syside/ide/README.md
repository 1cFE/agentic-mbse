Build full document semantic tokens for edits. Returns <span class="pre">`builder`</span> if successful, and <span class="pre">`None`</span> otherwise. Generally, <span class="pre">`None`</span> is returned if the <span class="pre">`document`</span> has nothing to highlight.

Internally calls <a href="/python/v0.8.4/syside/ide/SemanticTokensBuilder.md" class="reference internal" title="syside.ide.SemanticTokensBuilder.previous_result"><span class="pre"><code class="sourceCode python">SemanticTokensBuilder.previous_result</code></span></a> before building tokens.

Parameters<span class="colon">:</span>  
- **document** – The document to build full semantic tokens for.

- **id** – Previous result id. <span class="pre">`previous_result`</span> is called first, and if the <span class="pre">`id`</span> matches <span class="pre">`builder`</span> id the returned <span class="pre">`builder`</span> can be used to build edits.

- **encoding** – The position encoding to use for semantic tokens. Use Utf32 if interacting with Python strings.

- **multiline_tokens** – Whether to keep multiline tokens as is and not split them. Generally used for language clients that do not support multiline tokens.

- **builder** – The builder to collect semantic tokens into. Note that if provided, its internal state will be reset.

Returns<span class="colon">:</span>  
Provided <span class="pre">`builder`</span>, or new one otherwise, if there was anything to highlight.

Raises<span class="colon">:</span>  
**ValueError** – If <span class="pre">`encoding`</span>` `<span class="pre">`!=`</span>` `<span class="pre">`Utf8`</span>` `<span class="pre">`or`</span>` `<span class="pre">`not`</span>` `<span class="pre">`multiline_tokens`</span> and <span class="pre">`document.text_document`</span>` `<span class="pre">`is`</span>` `<span class="pre">`None`</span>. Utf8 encoding and <span class="pre">`multiline_tokens`</span> does not require a text source as all the required information is already contained in the CST.

Parameters<span class="colon">:</span>

- **range** – Range that should have all tokens highlighted. Implementation may return also build tokens outside of this range.

- **encoding** – The position encoding to use for semantic tokens. Use Utf32 if interacting with Python strings.

- **multiline_tokens** – Whether to keep multiline tokens as is and not split them. Generally used for language clients that do not support multiline tokens.

- **builder** – The builder to collect semantic tokens into. Note that if provided, its internal state will be reset.
