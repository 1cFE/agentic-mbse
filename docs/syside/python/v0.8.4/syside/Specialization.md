# Specialization <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#specialization-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">Specialization</span></span><a href="#syside.Specialization" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`Specialization`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> <span class="pre">`Specialization`</span> is a <span class="pre">`Relationship`</span> between two <span class="pre">`Types`</span> that requires all instances of the <span class="pre">`specific`</span> type to also be instances of the <span class="pre">`general`</span> Type (i.e., the set of instances of the <span class="pre">`specific`</span> Type is a *subset* of those of the <span class="pre">`general`</span> Type, which might be the same set).
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=53" class="reference external" target="_blank">7.3.2.3</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=169" class="reference external" target="_blank">8.3.3.1.8</a> of the KerML specification.
