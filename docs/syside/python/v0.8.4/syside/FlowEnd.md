# FlowEnd <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#flowend-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">FlowEnd</span></span><a href="#syside.FlowEnd" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`FlowEnd`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> A <span class="pre">`FlowEnd`</span> is a <span class="pre">`Feature`</span> that is one of the <span class="pre">`connector_ends`</span> giving the <span class="pre">`source`</span> or <span class="pre">`target`</span> of a <span class="pre">`Flow`</span>. For <span class="pre">`Flows`</span> typed by <span class="pre">`FlowTransfer`</span> or its specializations, <span class="pre">`FlowEnds`</span> must have exactly one <span class="pre">`owned_feature`</span>, which redefines <span class="pre">`Transfer::source::source_output`</span> or <span class="pre">`Transfer::target::target_input`</span> and redefines the corresponding feature of the <span class="pre">`related_element`</span> for its end.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=91" class="reference external" target="_blank">7.4.10.3</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=251" class="reference external" target="_blank">8.3.4.9.3</a> of the KerML specification.
