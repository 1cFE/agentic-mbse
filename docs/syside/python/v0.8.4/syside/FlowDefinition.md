Implementation of <span class="pre">`FlowDefinition`</span> defined in the SysML specification.

**Specification**:

> <div>
>
> A <span class="pre">`FlowDefinition`</span> is an <span class="pre">`ActionDefinition`</span> that is also an <span class="pre">`Interaction`</span> (which is both a KerML <span class="pre">`Behavior`</span> and <span class="pre">`Association`</span>), representing flows between <span class="pre">`Usages`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=113" class="reference external" target="_blank">7.16.2</a> of the SysML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=338" class="reference external" target="_blank">8.3.16.2</a> of the SysML specification.

**Specification**:

> <div>
>
> The <span class="pre">`features`</span> of the <span class="pre">`Association`</span> that identify the things that can be related by it.
