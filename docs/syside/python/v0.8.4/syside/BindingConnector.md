# BindingConnector <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#bindingconnector-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

Implementation of <span class="pre">`BindingConnector`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> A <span class="pre">`BindingConnector`</span> is a binary <span class="pre">`Connector`</span> that requires its <span class="pre">`related_features`</span> to identify the same things (have the same values).
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=77" class="reference external" target="_blank">7.4.6.3</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=214" class="reference external" target="_blank">8.3.4.5.2</a> of the KerML specification.
