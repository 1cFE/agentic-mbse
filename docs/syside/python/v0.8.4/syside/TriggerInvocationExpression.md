Implementation of <span class="pre">`TriggerInvocationExpression`</span> defined in the SysML specification.

**Specification**:

> <div>
>
> A <span class="pre">`TriggerInvocationExpression`</span> is an <span class="pre">`InvocationExpression`</span> that invokes one of the trigger <span class="pre">`Functions`</span> from the Kernel Semantic Library <span class="pre">`Triggers`</span> package, as indicated by its <span class="pre">`kind`</span>.
>
> </div>

For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=361" class="reference external" target="_blank">8.3.17.17</a> of the SysML specification.
