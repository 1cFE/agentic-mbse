# PortDefinition <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#portdefinition-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

Implementation of <span class="pre">`PortDefinition`</span> defined in the SysML specification.

**Specification**:

> <div>
>
> A <span class="pre">`PortDefinition`</span> defines a point at which external entities can connect to and interact with a system or part of a system. Any <span class="pre">`owned_usages`</span> of a <span class="pre">`PortDefinition`</span>, other than <span class="pre">`PortUsages`</span>, must not be composite.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=93" class="reference external" target="_blank">7.12.2</a> of the SysML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=328" class="reference external" target="_blank">8.3.12.5</a> of the SysML specification.
