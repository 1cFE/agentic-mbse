Implementation of <span class="pre">`ForkNode`</span> defined in the SysML specification.

**Specification**:

> <div>
>
> A <span class="pre">`ForkNode`</span> is a <span class="pre">`ControlNode`</span> that must be followed by successor <span class="pre">`Actions`</span> as given by all its outgoing <span class="pre">`Successions`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=132" class="reference external" target="_blank">7.17.3</a> of the SysML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=352" class="reference external" target="_blank">8.3.17.8</a> of the SysML specification.
