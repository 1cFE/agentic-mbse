# MetadataFeature <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#metadatafeature-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">MetadataFeature</span></span><a href="#syside.MetadataFeature" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`MetadataFeature`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> A <span class="pre">`MetadataFeature`</span> is a <span class="pre">`Feature`</span> that is an <span class="pre">`AnnotatingElement`</span> used to annotate another <span class="pre">`Element`</span> with metadata. It is typed by a <span class="pre">`Metaclass`</span>. All its <span class="pre">`owned_features`</span> must redefine <span class="pre">`features`</span> of its <span class="pre">`metaclass`</span> and any feature bindings must be model-level evaluable.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=95" class="reference external" target="_blank">7.4.13</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=259" class="reference external" target="_blank">8.3.4.12.3</a> of the KerML specification.
