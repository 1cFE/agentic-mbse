# EnumerationDefinition <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#enumerationdefinition-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">EnumerationDefinition</span></span><a href="#syside.EnumerationDefinition" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`EnumerationDefinition`</span> defined in the SysML specification.

**Specification**:

> <div>
>
> An <span class="pre">`EnumerationDefinition`</span> is an <span class="pre">`AttributeDefinition`</span> all of whose instances are given by an explicit list of <span class="pre">`enumerated_values`</span>. This is realized by requiring that the <span class="pre">`EnumerationDefinition`</span> have <span class="pre">`is_variation`</span>` `<span class="pre">`=`</span>` `<span class="pre">`true`</span>, with the <span class="pre">`enumerated_values`</span> being its <span class="pre">`variants`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=78" class="reference external" target="_blank">7.8.2</a> of the SysML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=314" class="reference external" target="_blank">8.3.8.2</a> of the SysML specification.
