# ChildrenNodes<a href="#childrennodes" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">ChildrenNodes</span></span><a href="#syside.ChildrenNodes" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Container that stores a vector of children nodes.

This is the primary object to modify the model through. In order to maintain type invariants, relationships can only be constructed internally by this container using the provided relationship type. The related element type is then checked against the types supported by the relationship and the container. However, due to limitations in the Python type system, this check can only be done at runtime. In addition, type system limitations do not allow generic <span class="pre">`TypeVar`</span> constraints which prevents fully resolved return types in this generic implementation.
