Implementation of <span class="pre">`Behavior`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> A <span class="pre">`Behavior`</span> coordinates occurrences of other <span class="pre">`Behaviors`</span>, as well as changes in objects. <span class="pre">`Behaviors`</span> can be decomposed into <span class="pre">`Steps`</span> and be characterized by <span class="pre">`parameters`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=78" class="reference external" target="_blank">7.4.7</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=219" class="reference external" target="_blank">8.3.4.6.2</a> of the KerML specification.
