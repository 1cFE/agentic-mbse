*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">ConcernDefinition</span></span><a href="#syside.ConcernDefinition" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`ConcernDefinition`</span> defined in the SysML specification.

**Specification**:

> <div>
>
> A <span class="pre">`ConcernDefinition`</span> is a <span class="pre">`RequirementDefinition`</span> that one or more stakeholders may be interested in having addressed. These stakeholders are identified by the <span class="pre">`owned_stakeholders`</span>of the <span class="pre">`ConcernDefinition`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=167" class="reference external" target="_blank">7.21.3</a> of the SysML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/2a-OMG_Systems_Modeling_Language.pdf#page=387" class="reference external" target="_blank">8.3.21.3</a> of the SysML specification.
