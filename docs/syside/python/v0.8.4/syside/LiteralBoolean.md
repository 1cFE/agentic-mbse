**Specification**:

> <div>
>
> <span class="pre">`LiteralBoolean`</span> is a <span class="pre">`LiteralExpression`</span> that provides a <span class="pre">`Boolean`</span> value as a result. Its <span class="pre">`result`</span> <span class="pre">`parameter`</span> must have type <span class="pre">`Boolean`</span>.
>
> </div>

For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=241" class="reference external" target="_blank">8.3.4.8.9</a> of the KerML specification.
