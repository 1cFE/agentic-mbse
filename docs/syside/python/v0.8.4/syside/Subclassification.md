# Subclassification <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#subclassification-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">Subclassification</span></span><a href="#syside.Subclassification" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`Subclassification`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> <span class="pre">`Subclassification`</span> is <span class="pre">`Specialization`</span> in which both the <span class="pre">`specific`</span> and <span class="pre">`general`</span> <span class="pre">`Types`</span> are <span class="pre">`Classifier`</span>. This means all instances of the specific <span class="pre">`Classifier`</span> are also instances of the general <span class="pre">`Classifier`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=58" class="reference external" target="_blank">7.3.3.3</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=182" class="reference external" target="_blank">8.3.3.2.3</a> of the KerML specification.
