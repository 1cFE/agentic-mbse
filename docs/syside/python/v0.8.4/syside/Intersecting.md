# Intersecting <span class="sd-sphinx-override sd-badge sd-outline-primary sd-text-primary">SysML</span><a href="#intersecting-sysml" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

*<span class="pre">class</span><span class="w"> </span>*<span class="sig-name descname"><span class="pre">Intersecting</span></span><a href="#syside.Intersecting" class="headerlink" title="Link to this definition"><span class="nerd-font"></span></a>  
Implementation of <span class="pre">`Intersecting`</span> defined in the KerML specification.

**Specification**:

> <div>
>
> <span class="pre">`Intersecting`</span> is a <span class="pre">`Relationship`</span> that makes its <span class="pre">`intersecting_type`</span> one of the <span class="pre">`intersecting_types`</span> of its <span class="pre">`type_intersected`</span>.
>
> </div>

For language description, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=56" class="reference external" target="_blank">7.3.2.7</a> of the KerML specification. For more details on the model, see section <a href="https://raw.githubusercontent.com/Systems-Modeling/SysML-v2-Release/refs/tags/2025-07/doc/1-Kernel_Modeling_Language.pdf#page=169" class="reference external" target="_blank">8.3.3.1.7</a> of the KerML specification.
