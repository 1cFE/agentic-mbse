# Automator<a href="#automator" class="headerlink" title="Link to this heading"><span class="nerd-font"></span></a>

Syside Automator is a Python library that enables the analysis and optimization of SysML v2 models, automation of modeling workflows, and building custom applications. The library utilizes the latest features of Python such as typing hints and generics making it easier to write correct Python code that queries and manipulates SysML v2 models.
